# Revision 1 → revision 3 gap work list

Produced 2026-10-09 by an independent read-only gap analysis of branch
`mvp` (built against spec revision 1) against spec revision 3. The full
row-by-row map was delivered in the session; this file keeps the work
sets and the security findings so implementers can work from it. Each
work set ends green under the CLAUDE.md gate and is committed on its own.

## Rulings (ledger R45–R47)

  rewritten in place (no `0002`); `.sqlx/` regenerated. Forward-only
  applies from the first release.

  support stays in `crates/api/src/testing.rs`. Equivalent to the plan.

## Security findings beyond the record (all closed by the sets above)

1. `GET /sites/{id}/env` returned `postgres_url` plaintext to viewers (WS1/WS8).
2. `helper write-file --mode 4755 --owner root` = setuid root from the agent user (WS2).
3. `Backup.dest`/`Restore.src` let the control plane steer `pg_dump -f` as postgres (WS4/WS5).
4. Prompt answers unsealed in `jobs.payload`; commands never redacted (WS4/WS6).
5. Join token and operator password on argv (WS7/WS8).
6. `agent.toml` world-readable between create and chmod (WS7).
7. Env values with newlines not rejected (WS2).
8. Unauthenticated Swagger UI (WS8).
9. `sudo` without `-n` can hang the agent (WS2/WS4).
10. Rollback left the new binary running (WS6).
11. cgroup path bug: metrics always 0 (WS2/WS7).
