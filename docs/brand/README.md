# Setu brand

"Setu" is Sanskrit for bridge. The mark is a keystone: a chevron span resting on its base, two
solid shapes so it survives 16 px and reads as a bridge from a distance.

| File | Use |
|---|---|
| `setu-mark.svg` / `setu-mark-dark.svg` | the mark alone, indigo on light / white on dark |
| `setu-icon.svg` | app icon: white mark on an indigo rounded square (favicon, PWA, social avatars) |
| `setu-logo.svg` / `setu-logo-dark.svg` | mark + wordmark lockups |
| `github-banner.svg` / `.png` | 1280×640 social preview (upload under repository Settings → Social preview) |

Colours: indigo `#4F46E5` (accent), navy `#0B1020` (dark surface), ink
`#0F172A` (light-mode text). Type: Inter (wordmark weight 600, tracking
−3 %). Keep the mark's clear space at least the height of the deck
stroke; never recolour the mark outside these three colours.
